# Upgrade to 0.3.0-preview.39

This preview updates the CloudPulse Web interface and keeps all workspace package versions synchronized. It does not add a database migration: Controller state remains at schema 10, and Agent protocols 1.0/1.1 retain the compatibility rules in [the compatibility matrix](../compatibility.md).

## Operator-visible changes

- Existing workbenches share desktop/mobile navigation and preserve real API data, permissions, automatic collection and entity details.
- Unsupported settings capabilities show unavailable states rather than locally simulated saves.
- SSH management is a frontend capability preview. Authorized host discovery is read-only; local drafts do not run prechecks or mutate hosts. Real signing, downloads, revocation, takeover and recovery remain unavailable until backed by services.

## Upgrade and validation

Keep Controller and Web at the same package version. Follow the existing backup, signed-artifact and upgrade procedures; do not infer release certification from a Git checkout. Verify login, navigation, device-width layouts, read-only collection timestamps and existing operational permission gates after an approved deployment.

No deployment, tag or release publication is performed by this UI commit. Roll back through the existing verified backup and artifact procedures; do not delete or downgrade Controller data.
