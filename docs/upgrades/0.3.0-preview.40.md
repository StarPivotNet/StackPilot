# Upgrade to 0.3.0-preview.40

This is a preview source update, not a deployment or production certification.

## Changes

Controller-Agent task delivery now redelivers unacknowledged dispatches with the same execution attempt, limits concurrency to four tasks per node, and serializes site operations. Persisted results are retried independently; delayed events remain subject to signed-request freshness, node ownership, attempt checks and clock bounds.

Generic user-created site tasks must use dedicated site workflows; terminal tasks additionally require terminal execution permission. SQLite control-state reads are projected and writes preserve unrelated task ciphertext. State, encryption and security audit records share a transaction.

## Compatibility and validation

Controller and Web package versions must match. Schema 10 and the documented Agent protocol compatibility remain unchanged; no new schema migration is introduced. Back up Controller state using the documented procedure before a real upgrade. Source tests and local builds do not replace deployment, multi-node or real-environment acceptance.

No service deployment, tag or release artifact is performed by this source commit.
