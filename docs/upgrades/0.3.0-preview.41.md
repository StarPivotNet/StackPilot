# Upgrade to 0.3.0-preview.41

This preview adds the Controller foundation for managed SSH access. It is not a complete SSH takeover release: the native PAM module, privileged host executor, independent connection verifier and Web integration are not implemented. Host takeover requests return `503 NOT_READY`, and credential issuance requires trusted host verification and an acknowledged policy revision. No management endpoint can manufacture either acknowledgement.

## Database and compatibility

Back up the Controller database before upgrading. Schema 11 adds SSH host, policy, credential, session and takeover-plan tables without changing existing identity or Agent state. Schemas 1–10 upgrade through the existing migration runner. Agent protocols 1.0 and 1.1 remain unchanged. Workspace packages and internal dependency references are synchronized to this preview.

Rollback to a schema 10 Controller requires restoring the verified pre-upgrade database backup. Do not downgrade the database in place. Installing or upgrading this version does not change sshd, PAM, system accounts, sudoers or existing server connections.

## Implemented behavior

- Explicit SSH permissions and per-user/per-node policy records, with shell, service-operator and explicitly granted host-admin profiles.
- Session and reauthentication protected APIs; personal API tokens cannot issue credentials.
- Digest-only 256-bit one-time credentials, a 15-minute authentication window, an independently bounded 8-hour session duration, transactional consumption and issuance throttling.
- Credential revocation and durable session-termination requests. A request is not a host-confirmed termination.
- Identity and policy changes invalidate related credentials and request session termination in the owning database transaction.
- Read-only, scope-filtered state APIs with backend timestamps and no-cache responses.

See [SSH access implementation status](../ssh-access.md) for interfaces, remaining host work and acceptance gates. This change does not deploy software or enable SSH takeover on any server.
