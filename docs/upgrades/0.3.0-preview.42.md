# Upgrade to 0.3.0-preview.42

This preview adds the independent SSH helper identity boundary. It does not yet install a native PAM module or implement host takeover, local scopes, rollback or Web workflows. Those capabilities remain disabled until the actual host executor and independent connection verifier are available.

## Changes

- Add administrator/session/reauthentication protected helper enrollment and revocation APIs scoped to an existing node.
- Accept one-use, five-minute helper enrollment credentials only on the HTTPS machine listener. Store token digests and Ed25519 public keys; no helper private key is sent to the Controller.
- Bind signatures to the SSH-helper purpose, node, credential, HTTP method, complete path/query and exact body digest. Persist replay nonces and reject revoked identities, revoked nodes, stale signatures and credentials from other trust domains.
- Replacement or revocation clears existing host verification, revokes issued credentials and records session termination requests. A signed readiness report cannot establish successful takeover.
- Repair missing optional dependency entries in the npm lockfile using npm 10's resolver. The previous main and preview.41 failed `npm ci` on Node 22 CI before tests could run; npm 10 clean-install dry-run now succeeds.

## Upgrade and rollback

Back up the Controller database before upgrading. Schema 12 adds helper enrollments, public credentials and replay nonces. Schemas 1–11 upgrade through the standard runner. Restore the verified pre-upgrade database when rolling back to a schema 11 Controller; do not perform an in-place downgrade. Agent protocols 1.0/1.1 are unchanged.

All workspace versions, internal references, backup/preflight/release schema metadata and current documentation are synchronized. No sshd configuration, system account, sudo rule, existing server connection or deployment is changed by installing this preview.
