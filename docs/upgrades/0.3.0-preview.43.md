# Upgrade to 0.3.0-preview.43

This preview adds the root-only SSH helper workspace, its fixed Unix socket protocol, a native Linux PAM module, a signed HTTPS client, and local session-scope supervision. Full takeover remains disabled: account/sudo provisioning, transactional sshd configuration changes, independent SSH verification, the installer and Web workflows still require implementation and real Linux acceptance.

## Implemented boundaries

- The helper runs independently as root on native Debian 12/Ubuntu 24.04 x86_64 with systemd and cgroup v2. Agent privileges are unchanged. Containers and other platforms are rejected.
- Enrollment uses a root-only credential file. The private Ed25519 key stays in a mode-0700 root state directory with mode-0600 files and atomic writes; existing symlinks and unsafe ownership/modes are rejected.
- PAM communicates only with the fixed root-only socket, verifies the server's kernel peer UID, supplies process identities from its own process, and validates authentication/account/session hooks before allowing access.
- Connection supervision checks boot ID, process ancestry, process start identity and actual cgroup membership. Each scope has an independent systemd runtime deadline, no delegation and whole-group termination. Restarting the helper does not recreate or extend an accepted lease.
- Controller partitions reject new logins while existing sessions retain their original deadline. Confirmed revocation closes the scope. Failed stops stay pending; host acknowledgements require matching node and connection IDs and are recorded only after the scope is empty and the original monitor is gone.
- Add a root Ubuntu CI job for the native PAM ABI and protected-storage tests. This is an ABI/protocol test and does not certify full SSH takeover or Debian VM acceptance.

## Regression fixes and release

The Controller backup service now accepts schemas 11/12, fixing the Linux backup tests exposed after dependency installation was restored. The Compose smoke job receives the current package version instead of falling back to preview.1. Linux scripts, units, native source and workflows have explicit LF checkout rules.

Schema remains 12; Agent protocols remain 1.0/1.1. Workspace versions and internal references advance together. Release archives include the helper and compiled passive PAM module; native compilation requires `make`, a C compiler and `libpam0g-dev`. No installer starts this service or changes the active PAM/sshd configuration in this preview. Rollback uses the existing verified database and release procedure.
