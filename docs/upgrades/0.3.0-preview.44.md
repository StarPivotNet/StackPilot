# Upgrade to 0.3.0-preview.44

This preview provisions separate, UUID-bound Linux identities and applies fixed SSH privilege profiles through the independent root helper. Complete SSH takeover remains disabled until configuration transactions, independent fresh-connection verification and the Web workflows are implemented and accepted. Software upgrades do not change sshd authentication.

## Accounts and privileges

- Existing Linux accounts, homes and unowned sudo files are never adopted. Account creation has a durable dispatch journal; an uncertain `useradd` result requires explicit recovery instead of automatic replay.
- Ordinary shell accounts have no sudo. Service operators receive exact calls to a non-setuid native service wrapper, with a root-only per-account allowlist. Full host administration requires an explicit `host-admin` policy and permits passwordless root sudo.
- Restricted services require a private non-root identity, no capabilities, `NoNewPrivileges=yes`, root-owned binaries and unit files, `DefaultDependencies=no`, and no lifecycle propagation or additional activation dependencies. `system.slice` is the only permitted implicit requirement. SSH, StackPilot, systemd and other control services are excluded. Unsupported services must be reconfigured and reviewed before granting this profile.
- Every account check verifies its real UID, group membership, managed sudo files and effective sudo listing. Extra privileges inherited through another sudoers source reject the account. Policy changes terminate old sessions before changing grants; unchanged reconciliation preserves live connections.
- Signed application acknowledgements bind the node, policy revision, effective enablement and actual UID. The Controller exposes pending/failed application separately and cannot issue credentials from a failed application.

## Compatibility and rollout

Schema remains 12; Agent protocols remain 1.0/1.1. Workspace versions and internal dependencies advance together. Native release archives include the PAM module and service wrapper. The separate Agent remains non-root. No production host has been taken over by this change.

Disposable Debian 12 and Ubuntu 24.04 systemd VMs each passed all 25 helper/native tests, including native compilation, actual account/sudo/service operations and PAM ABI checks. Windows passed the 41 applicable Controller/helper tests (six Linux permission tests skipped), workspace type checking, targeted lint and two release workflow tests. These checks do not yet certify complete sshd takeover, rollback, SFTP/SCP or network-partition acceptance. GitHub validation remains pending until the workflow changes can be pushed with the required OAuth permission.
