# Upgrade to 0.3.0-preview.45

This preview adds read-only native SSH preflight and a complete managed configuration builder. It does not apply that configuration or enable SSH takeover. Controller plan execution, independent rollback, fresh-connection verification and the Web workflow remain pending.

- `node apps/ssh-helper/dist/main.js preflight` inspects the native Debian 12/Ubuntu 24.04 systemd service, socket activation, startup environment, every TCP listening entrance, OpenSSH host fingerprints, SSH/PAM Include files, Match conditions and existing privileged connection identities. Unsupported service overrides, additional SSH listeners, unrecognized SSH daemons and non-native OpenSSH versions reject preflight.
- The receipt contains hashes and metadata for the inspected files, authentication-source summaries and a stable configuration digest. Private host keys and authorization-command arguments are never returned. Merely running preflight leaves SSH and PAM configuration unchanged.
- A flat managed configuration preserves verified listening endpoints and host keys, restricts authentication to the PAM helper, blocks direct root login and old authentication sources, disables forwarding and uses internal SFTP. It inherits no Include/Match rules. The generated PAM stack contains no session hook that can move users outside their connection scope.
- Root state now rejects unsafe writable ancestors as well as unsafe leaf directories.
- Real systemd tests verify process attachment, non-delegation, whole-group termination and independent local expiry; attempts to recreate an existing scope cannot renew it.

Disposable Debian 12 and Ubuntu 24.04 native systemd VMs each passed all 32 helper/native tests, including the root CLI preflight, `sshd -t/-T` checks for different user identities and extra-listener rejection. Windows passed 21 applicable helper tests (seven Linux root tests skipped), helper type checking and targeted lint. These checks do not yet certify actual PAM SSH login, configuration switching, rollback or Controller partition recovery.

Schema remains 12 and Agent protocols remain 1.0/1.1. All workspace versions, internal dependencies, the lockfile and current version documentation advance together. Installing this preview does not change authentication on existing hosts. GitHub CI remains pending while the OAuth workflow permission is unavailable.
