# Upgrade to 0.3.0-preview.47

This preview connects the SSH Controller takeover API to the root helper and an independent SSH verifier. It does not automatically install a helper, change SSH configuration or take over existing servers. The Web SSH screens and production installer are still pending; use disposable supported VMs for development validation.

The database remains schema 12; there is no new migration in this preview. Controller and Web workspace versions must match. Back up the database before upgrade; older binaries must not open a database containing newer SSH plan payloads. There is no automatic down migration.

Takeover requires an explicitly applied policy for the current operator, a separately enrolled SSH helper, a confirmed out-of-band recovery path, a complete preflight and a fresh one-use reauthentication proof for application. The Controller records successful independent checks before issuing commit. The five-minute local rollback remains active until commit and works without Controller/helper availability.

Basic PAM login, UID/sudo checks, SFTP, forwarding denial, negative authentication, local connection expiry, concurrent OTP consumption and online revocation were exercised on disposable Debian 12 and Ubuntu 24.04 systemd VMs. This is not the complete acceptance matrix: all profiles, normal-client multiplexing/SCP, network and helper faults, non-root Agent coexistence and browser acceptance still require verification. No production host was changed.

Publishing this preview remains subject to the repository's full CI and security gates. The Controller production dependency audit is clean; repository-wide development dependency findings still require resolution. See [SSH implementation status](../ssh-access.md).
