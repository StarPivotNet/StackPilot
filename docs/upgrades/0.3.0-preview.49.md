# Upgrade to 0.3.0-preview.49

This preview connects SSH management pages to the real scoped API and adds explicit independent reverification after exact restoration of a committed host's configuration. Software upgrades do not install, enroll or activate a root helper and never take over SSH automatically.

Database schema remains 12. Keep Controller and Web versions aligned and back up persistent state before upgrades. Existing enrolled helper identity and root takeover journals must be preserved. There is no automatic down migration.

SSH navigation now requires `ssh:read`. Connection, management and termination actions retain their separate permissions, explicit node scope and single-use reauthentication requirements. Platform administrator status alone does not grant a Linux root policy. Lists never expose passwords; issuance responses are displayed once and are not saved in browser storage.

A drifted committed host stays unavailable until an operator restores its exact committed configuration and explicitly requests reverification. A fresh signed host report and all independent SSH checks are required. This action does not restore older authentication or modify the committed root proof. Failure, cancellation and Controller restart leave access paused.

Desktop/mobile browser checks and basic VM reverification passed. The complete Linux client/profile/fault matrix, real non-root Agent coexistence and release/security CI gates remain outstanding. See [current SSH acceptance evidence](../ssh-access.md#current-vm-acceptance-evidence).
