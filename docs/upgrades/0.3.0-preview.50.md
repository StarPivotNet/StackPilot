# Upgrade to 0.3.0-preview.50

This preview updates compatible dependency resolutions and pins the Web runtime to Nginx 1.30.6 on Alpine 3.24 slim. Rebuild and verify release artifacts/images from the locked sources. No database or SSH authentication changes occur automatically; schema remains 12.

The npm high/critical audit gate is retained. The development audit still reports moderate findings in the TypeScript lint and native build-tool dependency chains; this release does not suppress them or force an incompatible tool downgrade. Production dependencies and built container images are scanned separately.

Native CI now validates the hosted runner's sudo configuration after correcting its existing grant permissions. The Linux entrypoint test uses its source location instead of relying on the caller's working directory. These changes do not weaken root helper ownership, sudo or SSH preflight checks.

SSH's broader fault/profile acceptance work remains in progress. Preserve helper identities and committed journals during upgrades; software upgrades never take over a host automatically.
