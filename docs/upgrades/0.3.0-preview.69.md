# Upgrade to 0.3.0-preview.69

This preview adds the egress relay path described in the mesh plan (M4). Database schema remains 12; no migration is required.

Before enabling egress routing:

1. Install the new `stackpilot-mesh-helper` units (`stackpilot-mesh-helper.socket`, `stackpilot-mesh-helper@.service`, plus the sysusers and tmpfiles entries) so each node can report its overlay identity and link state.
2. Set `STACKPILOT_EGRESS_PROBE_TARGETS` on the Controller to comma-separated https origins without a path. Without it the probe never runs, the quality table stays empty, and every download fetches directly.
3. Confirm the overlay firewall allows data plane port 18080 between peers; the proxy refuses to bind anything that is not the assigned overlay address.

An egress that does not match the Controller peer directory entry is not called: the fill degrades to a direct fetch with `EGRESS_UNKNOWN_PEER` instead of signing a request for an unchecked address.
