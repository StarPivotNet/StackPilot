# Upgrade to 0.3.0-preview.70

This preview changes only the Web table layout: a trailing control column now takes the width its call site declares (at least 80px) instead of being pinned to 80px whenever its key was `ops` or `actions`. Controller, Agent and helper builds are unchanged, database schema remains 13, and no configuration is required.

Operators will see wider 操作 columns on 文件 (170px), 回收站 (184px) and 证书续期 (152px) and 下载任务 (96px); 主机、数据库、站点 keep the 80px floor. Data columns still take an even share, so no page gains horizontal scrolling. Only the Web bundle needs redeploying; the Controller and nodes can stay on the previous build.
